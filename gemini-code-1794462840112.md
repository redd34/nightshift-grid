# Nightshift Grid ⚡️

**Turn idle laptops, office PCs, and legacy mini-PCs into a zero-CapEx, fault-tolerant local AI batch & GraphRAG cluster.**

Nightshift Grid is a lightweight distributed compute engine ("SETI@home meets local enterprise MapReduce") that harvests idle cycles across heterogeneous local machines without slowing down human users. 

Instead of slicing a single giant model across slow LAN links (where Wi-Fi jitter destroys token throughput) or locking out older hardware, Nightshift treats every machine on your network as a **preemptible, fenced micro-worker** running quantized small models (`qwen3:4b`, `qwen2.5:3b`, `phi4-mini`) via Ollama or `llama.cpp`.

---

## Why This Exists (The Problem with Local AI Routers)

Most enterprises and developer teams have terabytes of unstructured PDFs, logs, and tickets that cannot be sent to cloud APIs due to cost or privacy—while dozens of office PCs, laptops, and mini-PCs sit 90% idle all day and 100% idle overnight.

Existing local clustering tools leave a massive gap for real-world batch pipelines:
1. **Tensor-Splitting Clusters (`exo`, `petals`, `llama.cpp RPC`):** Slicing one 70B model across laptops over Wi-Fi bottlenecks on network serialization, and if a single laptop closes its lid mid-prompt, the entire forward pass crashes.
2. **Stateless Local Proxies (`NVIDIA PAIR`):** PAIR only routes single HTTP chat requests and artificially gates out hardware older than RTX 20-series GPUs or Apple M4 chips. If a node drops mid-request, the job fails.

### How Nightshift Grid Compares

| Feature | Exo / Petals | NVIDIA PAIR | GPUStack | **Nightshift Grid** |
|---|---|---|---|---|
| **Execution Model** | Layer-splitting | Stateless HTTP proxy | Dedicated server pool | **Stateful MapReduce + Lease Queue** |
| **Hardware Support** | Mostly Apple Silicon / GPUs | Locked to RTX 20+ & M4+ | Dedicated GPUs | **Any CPU/RAM/GPU (x86, M1–M4, mini-PCs)** |
| **Human Preemption** | None | Basic GPU busy check | None | **<65ms HID detection + <250ms GPU drop** |
| **Mid-Task Crash Recovery** | None (Cluster halts) | None (HTTP 500) | Minimal | **Fenced leases + instant chunk re-queue** |
| **Built-in GraphRAG Sink** | No | No | No | **Deduplicated JSONL / Qdrant triples** |

## Key Architectural Highlights & Live Benchmarks

### 1. True Sub-250ms GPU Yielding (Closing the Prompt-Eval Blind Spot)
A common trap when wrapping local inference servers (`Ollama` / `llama.cpp`) in Python is breaking out of a token-reading loop without tearing down the underlying socket—which leaves the local GPU pegged at **84–94% utilization** until generation finishes. Furthermore, checking for user activity *only* when tokens arrive creates a blind spot while the model is loading weights or evaluating a long prompt.

Nightshift runs inference inside an isolated async task while an out-of-band OS HID watcher polls every 500ms (`ioreg -c IOHIDSystem` on macOS, `GetLastInputInfo` on Windows, `xprintidle` on Linux). The millisecond a human touches the mouse or keyboard, the watcher fires `task.cancel()` and closes the `httpx` stream, sending an immediate TCP `FIN/RST` to Ollama.

| Worker Cancellation Method | Local GPU Utilization Afterwards (`qwen3:4b`) |
|---|---|
| Stop reading loop, leave response open | **84–94% until model finishes** |
| Error raised inside `async with client.stream` | **0% within 250ms** (next request ready in 0.04s) |
| Out-of-band `task.cancel()` (covers model load & prompt eval) | **0% within 250ms** |

### 2. End-to-End Chaos & Preemption Benchmarks
Tested across 3 workers (`qwen3:4b`, ~130 tok/s decode) processing a 24-chunk industrial maintenance GraphRAG extraction job:

| Chaos Scenario / Metric | Measured Result |
|---|---|
| **Live Human Preemption** (User returns mid-job on `node-legacy-laptop`) | **24/24 chunks completed** in 44.8s, 0 failures |

## Core Distributed Systems Guarantees

* **Fenced Leases (Split-Brain Prevention):** Every task assignment carries a unique `lease_id`. If a worker experiences a network partition or stalls past its TTL, its lease is revoked. Heartbeat responses explicitly notify stale workers that their lease was reassigned so they abort compute immediately and cannot overwrite completed results.
* **Race-Free Pull & Pause:** If a human touches the mouse while a task pull is in flight over the network, the newly acquired lease is immediately returned to the Coordinator. Late pause signals cannot accidentally revoke newer leases.
* **Graceful `SIGTERM` Handback:** Stopping a worker daemon immediately releases its active lease back to the queue rather than waiting for the 12-second lease reaper.
* **Dead-Letter Poison Pill Protection:** Chunks that fail due to malformed prompts or model errors are retried up to 3 times before being parked as `FAILED`. Human preemptions do *not* increment the failure counter.
* **Canonical Graph Edge Normalization & Idempotent Sink:** Constrained JSON output enforces `[subject, RELATION, object]` triples, normalizes relation verbs across chunks, disables reasoning-token overhead on thinking models (`qwen3`), and guarantees idempotent writes to `output_graph.jsonl` by deduplicating `task_id`s across restarts.
